# Camera-ready runs — rules fixed before any result is inspected

NeurIPS 2026 submission 24168, camera-ready due 2026-11-06.
Written 2026-10-11, before the first camera-ready run was launched. No result of the camera-ready generation
had been produced or inspected when these rules were fixed. Any later change is recorded in the amendment log
at the end of this file, with date and reason.

## 1. What is rerun, and why

The submitted and rebuttal-era result files were produced over seven months by many code states, most of them
uncommitted (`git_dirty=True` in 38,630 of 42,664 files with provenance; 15,272 files with no provenance at all),
in two Python environments, with two decoder protocols (stochastic Gumbel decoding before 2026-03-27, greedy
decoding with an 80-token cap from 2026-04-12). The camera-ready therefore regenerates, from one commit, in one
environment, on one machine type, every GuacaMol arm that the repository can still run. The purpose is
provenance and internal consistency, not new results.

## 2. Rules

**R-1 Runner.** Every GuacaMol arm runs through the per-cell path `scripts.run_benchmark.run_benchmark()`, one
fresh process per (solver, task, seed) cell, with the CLI defaults that produced the existing files:
`mode=ours, max_iter=25, n_cold_start=5, n_initial_points=10, latent_dim=128, subspace_dim=16, n_subspaces=16,
cold_start_source=zinc, norm_mode=fixed, codec_type=selfies`. Reason: this is the code path behind the posted
rebuttal numbers and the submitted Table 1/2 rows. On 2026-10-11 it reproduced the July files bit for bit for
`linear_bo`, `papenmeier_msr_box_faithful`, `xu_standard_gp_box_faithful` and the clean July
`hvarfner_scaled_gp_sphere_continuous` files at commit `abbd61e`. The batch runner
(`scripts/run_geowalk_family_batch.py`) draws different random streams for arms with a continuous acquisition
optimiser and is not used for camera-ready runs.

**R-2 One commit, one environment, one machine type.** All GuacaMol runs use the tagged camera-ready commit
(branch `camera-ready` = `abbd61e` + device-mismatch fix + published-MSR solvers + fixed-box TuRBO solver + run
tooling), a clean tree (`git status --porcelain` empty, so provenance records `git_dirty=False`), the
environment `/scratch/prusek/envs/neurips` on panda (package-identical to kajman's `.venv312`: 114 packages,
torch 2.11.0, botorch 0.17.2, gpytorch 1.15.2), and panda's 2× NVIDIA L40S (driver 610.57.04), with
`OMP_NUM_THREADS=MKL_NUM_THREADS=OPENBLAS_NUM_THREADS=4` (shown bit-identical to the default thread count).
CPU-only arms (GaBO, Matérn-GaBO) and the LassoBench runs execute on kajman's CPU (same Xeon Gold 6542Y model)
from a clone at the same commit; the host is recorded in each file's provenance.

**R-3 Printed generation.** For every arm that has a camera-ready-commit run, the camera-ready paper prints
that run. Values from earlier generations (submitted PDF, posted rebuttal, E-1, September blocks) appear only
in the correspondence appendix ("posted/submitted vs printed"). This rule holds whatever the new numbers turn
out to be.

**R-4 Fixed implementations are added, never substituted.** Where an existing arm deviates from its published
method, a corrected implementation runs under a new solver name next to the old arm:
`papenmeier_msr_published` (published MSR acquisition maximiser) next to `papenmeier_msr_box_faithful`
("MLE (scaled)", MSR without RAASP); `turbo_box_faithful` (TuRBO-1 on the fixed `[p01, p99]` box) next to the
submitted TuRBO row (box of the observed latents). Which row the paper prints is the authors' decision; both
are reported.

**R-5 Cells.** Each arm runs on the 11 paper tasks (adip, dhop, fexo, med1, med2, osmb, pdop, rano, shop, siga,
zale) × seeds 42–81 = 440 cells. No completed cell is ever deleted or rerun. Crashed cells and GP-fallback
steps are counted and reported. Matched sets are the intersection of completed cells of the arms in a table;
their size is printed in every table.

**R-6 Analysis defaults** (the authors may choose otherwise; the generator also writes the alternatives):
levels are means of per-task means; paired comparisons use the cell-level Wilcoxon signed-rank test and
Cohen's d on matched cells, with Benjamini–Hochberg correction within a table; every headline comparison also
reports tasks won out of 11 and an exact task-level Wilcoxon test.

**R-7 E-1 stays.** The September rerun E-1 (`em1_premise`, commit `abbd61e`, batch runner) is kept as an
independent-random-stream replication of the support × acquisition-maximisation factorial and is reported in
the factorial appendix.

**R-8 No result-driven reruns.** After the first camera-ready result has been inspected, a run may be repeated
or added only for a reason written into the amendment log below (for example a crash with a code cause), and
the earlier output is kept.

## 3. Not rerun (disclosed instead)

| Arm or experiment | Reason |
|---|---|
| TuRBO (submitted row), BAxUS, LOL-BO, InvBO, full-dimensional CMA-ES | Ran through a separate harness (`src/benchmark/runner.py`, deleted in `68ed3dc`); its environment and the vendored LOL-BO/InvBO reference code no longer exist. Deviations are listed in the baseline appendix. |
| SAASBO (10 seeds) | About 50 process-hours per 10 seeds; its `[-5, 5]^256` box is itself a deviation. |
| COWBOYS (10 seeds) | The implementation is not the published method (Thompson sampling over 20 Gaussian candidates at latent norm ≈ 64, stochastic decoding). Recommended: drop the row; the decision is the authors'. |
| NAS-Bench-101 | Benchmark data and VAE weights are lost; the stored per-seed results are used as they are. |
| Cross-codec appendix (Chembed, Power-Spherical) | No environment loads these codecs; the stored per-seed results are used as they are. |
| LassoBench GP arms | The code that produced them is not recoverable; disclosed. Targeted reruns only (Papenmeier D = 60 bit check, same-environment reruns of the cheap arms, Linear BO at D = 7129). |
| Budget-scaling appendix (N = 1000) | Relabelled, not rerun. |
| Stereo-token loss at encoding (63 % of ZINC-250k) | Shared by every arm and every cold start; disclosed, not rerun. |
